# Invincible-Hacker-HubFlow
## 简介 Introduction
**中文**
Invincible-Hacker-HubFlow 是由 Invincible Hacker 组织成员 snhk 开发、基于 Python 构建的轻量化服务端框架，集成图形化安装向导、多语言适配、版本权限管理、邮箱验证码激活、内网穿透等能力，结构模块化、部署简单，适合自研后台、私有服务与工具服务端快速搭建。

**English**
Invincible-Hacker-HubFlow is a lightweight server framework developed by snhk from the Invincible Hacker organization and built with Python. It integrates a graphical installation wizard, multi-language support, version permission management, email verification activation, intranet penetration and other features. With a modular structure and easy deployment, it is suitable for quickly building self-developed backends, private services and tool servers.

### 中文

- 🌐 全球多语言双语适配，可自由扩展语种

### English

- 🔖 Multi-version classification: permission isolation for HubFlow v1.2.1 Pro / Official Edition / Free Edition

- 🖥️ Graphical GUI installer with no console popup
- 📁 Custom installation path, automatic registry writing and version marking
- 🧩 Modular kernel design with unified core configuration management
